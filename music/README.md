# Your music goes here

Make one folder per album. The folder name becomes the album title.

```
music/
  Midnight Drive/
    cover.jpg
    01 - First Song.mp3
    02 - Second Song.mp3
  Summer Tapes/
    cover.jpg
    01 Another Song.m4a
```

- **Formats:** mp3, m4a, aac, wav, flac. Use mp3 or m4a to keep file sizes small.
- **Titles and order:** taken from the file's tags if it has them, otherwise from the file name. A leading number like `01 - ` sets the order and is left out of the title.
- **Covers:** a square `cover.jpg` around 1000 x 1000 px loads quickly and looks sharp on the lock screen.
- Songs placed directly in `music/`, outside any folder, appear under an album called "Singles".
